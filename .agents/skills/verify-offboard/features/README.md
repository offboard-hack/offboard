# Offboard verification map

Start with the [verification skill](../SKILL.md) and a seeded disposable database. Use a fresh Chromium context between independent journeys.

## Features

- [Entrar no portal](sign-in.md) covers invite-only access and return to a protected page.
- [Painel](dashboard.md) covers summaries, filters, and opening a case from the queue.
- [Desligamentos](cases.md) covers locating, opening, and creating a case.
- [Importar desligamentos](csv-review.md) covers both CSV entry points, validation, and persisted imports.
- [Checklist automático](checklist.md) covers template editing, dragging, undo, and saving the layout with API action synchronization.
- [Bens e coleta](equipment.md) covers the inventory, URL-backed status filters, and shipment tracking.
- [Administração e equipe](administration.md) covers the team roster, integration search, and plan tables.

Capture each entry point separately when a feature has more than one. Record blocked prerequisites or unexpected results with the action attempted and the supporting artifact. Candidaturas assistidas and Resultados e feedback are outside this map.
