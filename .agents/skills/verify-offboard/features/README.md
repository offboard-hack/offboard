# Offboard verification map

Use this seed map to verify the main HR workflows. Start from a new run of the [verification skill](../SKILL.md). Each mapped route uses the built-in sample data. Use a fresh Chromium context between independent journeys that mutate data.

## Features

- [Painel](dashboard.md) covers summaries, filters, and opening a case from the queue.
- [Desligamentos](cases.md) covers locating, opening, and creating a case.
- [Importar desligamentos](csv-review.md) covers both CSV entry points, validation, and preview completion.
- [Checklist automático](checklist.md) covers template editing, dragging, undo, and saving the layout with API action synchronization.
- [Bens e coleta](equipment.md) covers the inventory and URL-backed status filters.

Capture each entry point separately when a feature has more than one. Record blocked prerequisites or unexpected results with the action attempted and the supporting artifact. The remaining sidebar destinations are outside this seed map.
